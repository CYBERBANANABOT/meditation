# Медитации 🌌

Минималистичное приложение для медитаций, работающее как Telegram Mini App.

Основной интерфейс: [index.html](index.html). Рабочая ветка: `main`.

## Возможности

- Дыхательные практики и сканирование тела
- Настрой на практику при входе или по кнопке смены чакры слева от названия
- Название чакры и тема на главном экране, рекомендации — в «О чакре»
- Вертикальный барабан выбора времени от 1 до 180 минут
- Живая вселенная без отдельного переключателя режима погружения
- Две нижние вкладки: «Практика» и «Профиль»
- История практик, серия дней и дневник ощущений
- Встроенная инструментальная композиция и личные MP3

## Полная практика йоги (отдельная страница)

[Открыть 3D-инструктора хатха-виньяса](yoga-prototype.html).
Программа находится в `main`, но пока **не добавлена в навигацию медитации**:
сначала нужна проверка реальными пользователями и инструктором йоги.

**Продолжительность:** 18 минут 20 секунд, 26 последовательно соединённых асан:

- Приветствие солнцу: гора, руки вверх, наклон, полуподъём, планка, кобра, собака вниз.
- Стоячая серия: выпады, Воин I и II, треугольник с каждой стороны, переходы через собаку вниз.
- На коврике: планка, поза ребёнка, кошка-корова, бабочка, посох, мост, мягкие повороты лёжа.
- Заключение: шавасана.

**Реализация:** `assets/yoga-program.js` содержит тайминг и русские инструкции;
`assets/yoga-asanas.js` — ориентиры и промежуточные положения для 26 этапов;
`assets/yoga-rig.js` — IK-ограничения постоянной длины шеи, торса, рук и ног с коррекцией контакта с ковриком;
`assets/yoga-mannequin.js` — WebGL-рендерер деревянного манекена с цельной грудью, плечевыми шарнирами и короткой шеей;
`assets/yoga-prototype.js` — таймер, переключение, голосовые подсказки и пауза.
Всё работает без внешних 3D-библиотек или платных API. При отсутствии WebGL остаются текстовые инструкции. Автотест `tests/yoga-rig.cjs` проверяет все 26 асан и промежуточные кадры на растяжение сегментов и контакт с ковриком. Мобильный тест сохраняет скриншоты **каждой** из 26 поз, чтобы их можно было ревизовать визуально.

**Источники для структуры практики:** [Yoga Journal — 20-минутная последовательность](https://www.yogajournal.com/teach/teaching-methods/designing-a-20-minute-yoga-routine/), [Yoga Journal — утренняя йога](https://www.yogajournal.com/practice/yoga-sequences/morning-yoga-practice/), [Yoga Journal — приветствие солнцу](https://www.yogajournal.com/practice/sun-salutation-surya-namaskar/).
Последовательность самостоятельно адаптирована для приложения, а не скопирована целиком.

**Ограничение:** деревянная модель схематична. Анимации показывают положение тела, но не гарантируют корректную технику, безопасность для конкретного человека или полноценные переходы в реальном времени. Упражнения и модификации до широкого запуска должны быть проверены квалифицированным преподавателем йоги. При травмах или проблемах с позвоночником отдельные асаны могут быть противопоказаны ([NCCIH](https://www.nccih.nih.gov/health/yoga-effectiveness-and-safety)).

## Музыка

Стандартный трек — **«Peace of Mind» (Kevin MacLeod)**, около 36 минут, фортепиано и протяжные гармонии. Музыка лицензирована по **CC BY 4.0**, атрибуция и сведения об обработке приведены в [assets/MUSIC-LICENSE.md](assets/MUSIC-LICENSE.md).

Другие загруженные пользователями аудиофайлы хранятся локально в IndexedDB их устройства.

## Разработка и проверки

Код разделён без изменения функций приложения:

- assets/style.css — стили
- assets/core.js — хранилище, настройки, общие данные
- assets/visualizer.js — вселенная и дыхательная анимация
- assets/session.js — таймер, музыка, завершение
- assets/ui.js — экранные элементы, выбор чакры и запуск приложения
- assets/journal-backup.js — сохранение и восстановление дневника

Скрипты подключаются именно в таком порядке, как обычный JavaScript в одной странице.
Автоматические проверки: node --test tests/smoke.cjs
GitHub Actions запускает тесты при каждом push в main и в pull request.
Для обновления кешируемого кода в Telegram при крупных изменениях можно повышать
версию ?v= в index.html.
