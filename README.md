# Медитации 🌌

Минималистичное приложение для медитаций, работающее как Telegram Mini App.

Основной интерфейс: [index.html](index.html). Рабочая ветка: `main`.

## Возможности

- Дыхательные практики и сканирование тела
- Настрой на практику при входе или по кнопке смены чакры слева от названия
- Название чакры и тема на главном экране, рекомендации — в «О чакре»
- Вертикальный барабан выбора времени от 1 до 180 минут
- Живая вселенная без отдельного переключателя режима погружения
- Две нижние вкладки: «Практика» и «Профиль»
- История практик, серия дней и дневник ощущений
- Встроенная инструментальная композиция и личные MP3

## Экспериментальная йога

[Открыть отдельный 3D-прототип инструктора](yoga-prototype.html).
Он находится в `main`, но **не добавлен в навигацию основного приложения**:
сначала проверяем рендеринг и управляемость в Telegram WebView.

- `assets/yoga-mannequin.js` — автономный WebGL-рендерер деревянной шарнирной куклы с восемью различными мягкими движениями
- `assets/yoga-prototype.js` — полноценная 10-минутная последовательность из 8 этапов, точный таймер, пауза, переключение этапов, голосовые подсказки с напоминанием и завершение
- `assets/yoga-prototype.css` — самостоятельная мобильная вёрстка в стилистике Meditation
- Подсказки можно озвучить через системный синтез речи, если устройство его поддерживает
- Никаких внешних библиотек и платных API; при отсутствии WebGL остаются текстовые инструкции
- Автоматические тесты `tests/yoga-prototype.cjs`; скриншоты сохраняются в GitHub Actions

Программа «Мягкое утро» длится ровно **10 минут**: настрой и дыхание (1:00), плечи (1:00), подъём рук (1:30), вытяжение рук в стороны (1:30), кисти и стопы (1:00), перенос веса с опорой (1:30), спокойное дыхание (1:00), расслабление (1:30). Все этапы имеют отдельную анимацию; движения можно пропускать, ставить на паузу и возобновлять.

Это **прототип для демонстрации**, а не профессионально проверенный комплекс йоги или индивидуальная лечебная гимнастика. Для движений ног и переноса веса необходима устойчивая опора, доступен описанный вариант сидя. Техника и противопоказания требуют проверки специалистом до включения в основное приложение.

## Музыка

Стандартный трек — **«Peace of Mind» (Kevin MacLeod)**, около 36 минут, фортепиано и протяжные гармонии. Музыка лицензирована по **CC BY 4.0**, атрибуция и сведения об обработке приведены в [assets/MUSIC-LICENSE.md](assets/MUSIC-LICENSE.md).

Другие загруженные пользователями аудиофайлы хранятся локально в IndexedDB их устройства.

## Разработка и проверки

Код разделён без изменения функций приложения:

- assets/style.css — стили
- assets/core.js — хранилище, настройки, общие данные
- assets/visualizer.js — вселенная и дыхательная анимация
- assets/session.js — таймер, музыка, завершение
- assets/ui.js — экранные элементы, выбор чакры и запуск приложения
- assets/journal-backup.js — сохранение и восстановление дневника

Скрипты подключаются именно в таком порядке, как обычный JavaScript в одной странице.
Автоматические проверки: node --test tests/smoke.cjs
GitHub Actions запускает тесты при каждом push в main и в pull request.
Для обновления кешируемого кода в Telegram при крупных изменениях можно повышать
версию ?v= в index.html.
